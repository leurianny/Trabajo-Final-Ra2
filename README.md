# Trabajo-Final-Ra2
 Sistema de Ventas

Sistema de escritorio desarrollado en C# (.NET Windows Forms) para la gestión básica de ventas, generación de facturas y visualización de reportes utilizando ReportViewer (RDLC).

---

## 📋 Descripción

Este proyecto permite:

- Registrar clientes
- Agregar productos a una venta
- Calcular subtotales automáticamente
- Generar total general
- Visualizar factura en formato reporte (RDLC)

El sistema está diseñado como práctica académica para reforzar conceptos de:

- Programación en C#
- Manejo de DataGridView
- Envío de datos entre formularios
- Uso de ReportViewer (RDLC)
- Conexión a base de datos SQL Server

---

## 🛠 Tecnologías Utilizadas

- C#
- .NET Framework
- Windows Forms
- SQL Server
- ReportViewer (RDLC)
- Visual Studio

---

## Estructura del Proyecto

- `FormVentas` → Gestión de ventas
- `FormClientes` → Registro de clientes
- `FormProductos` → Gestión de productos
- `FormFactura` → Generación de factura
- `RptFactura.rdlc` → Reporte de factura
- `Conexion.cs` → Conexión a base de datos

---

##  Funcionalidades

✔ Registro de cliente  
✔ Agregar múltiples productos  
✔ Cálculo automático de subtotal  
✔ Cálculo de total general  
✔ Generación de reporte de factura  
✔ Visualización previa antes de impresión
